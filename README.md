# Dotfiles - KDE

Personal dotfiles with configuration files for applications and the [KDE Plasma](https://kde.org/plasma-desktop/) desktop environment.

## Installation using [YADM (Yet Another Dotfiles Manager)](https://yadm.io/)

```bash
sudo pacman -S --needed yadm
yadm clone https://github.com/DimitryGonzales/dotfiles-kde.git
yadm checkout --force
```

> [!CAUTION]
> This will overwrite existing config files that share the same paths as the ones in this repository.
